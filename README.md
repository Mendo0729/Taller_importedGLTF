## Ejecutar

~~~powershell
cd imported-models
npm install
npm run dev
~~~

El museo interactivo compara glTF, GLB, recursos Embedded, compresión Draco y animaciones.
Los dos PDF originales de la asignación se mantienen en la raíz del repositorio.
