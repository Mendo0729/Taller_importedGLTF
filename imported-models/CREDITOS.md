# Créditos y licencias de modelos

Los archivos de la carpeta static/models provienen del paquete de ejemplos
glTF aportado como recurso del taller. Referencia de origen:
https://github.com/KhronosGroup/glTF-Sample-Models

## Casco de vuelo (FlightHelmet)

- Autor/origen según README del modelo: Microsoft, donado para pruebas glTF.
- Licencia indicada por el archivo original: **CC0 1.0 (dominio público)**.
- Licencia: https://creativecommons.org/publicdomain/zero/1.0/
- Archivo utilizado: static/models/FlightHelmet/glTF/FlightHelmet.gltf.
- El modelo usa archivos .bin y mapas PBR externos que se deben conservar juntos.

## Herramientas

Three.js, Vite y DRACOLoader se usan como dependencias; sus licencias
respectivas están en los paquetes originales y el package-lock.json.

Antes de redistribuir este proyecto o publicar un paquete de modelos de uso
comercial, revisar individualmente las licencias de los modelos incluidos.
